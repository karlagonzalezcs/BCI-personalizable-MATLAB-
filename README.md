# Interfaz-Cerebro-Computadora-personalizable-MATLAB-

¡Hola!

Este es un proyecto en el que estuve trabajando como parte del Programa de Honores en la Universidad de las Américas, Puebla.

He subido en este repositorio todos los códigos que necesitas para poner a prueba la Interfaz Cerebro-Computadora que diseñé. Para esta interfaz, el equipo de adquisición de señales de electroencefalografía usado fue la Cyton Biosensing Board de 8 canales de OpenBCI y un Arduino Uno R4 Wi-Fi como dispositivo externo a controlar.

Los códigos fueron desarrollados en MATLAB, y para su correcto funcionamiento, es necesario que descargues lo siguiente:
- Signal Processing Toolbox
- Machine Learning and Deep Learning App
- App Designer

Para lograr la correcta comunicación entre MATLAB y el equipo de EEG, también es necesario que instales la librería brainflow, la cuál se encuentra en el siguiente link:
https://brainflow.readthedocs.io/en/stable/BuildBrainFlow.html#matlab
